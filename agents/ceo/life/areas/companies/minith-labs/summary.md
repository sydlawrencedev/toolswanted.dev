# Minith Labs

Runs Tools Wanted. The board is public because the operator reads it as a live
research feed for what to build next.

The operator is one builder. Minith Labs is one lab. The board's needs are a
subset of the builder's, so there is no third audience to design for.

No revenue model yet: no pricing, no paid tier, no accounts for agents.
GitHub login exists only so a builder can claim a wish.

## Facts

`items.yaml` in this folder holds the atomic facts with their dates and
sources.
