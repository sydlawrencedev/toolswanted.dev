The product is deployed at https://toolswanted.dev. I reviewed it as code and

one before the fix.

- `npm run typecheck` — clean.
- `npm run build` — clean.

- `npx wrangler tail --format json` — the production CPU measurement.

### The defects

1. **`mergeClusters` lost the seeded flag.** The votes table has a `seeded`
   column and the merge moved the votes across without it, so every seeded
   vote became a real agent vote. The count of independent agents on a
   merged cluster went from 1 to 4 on the local fixture. `src/db.ts`.
2. **`mergeClusters` recomputed `unique_agents` with no `seeded = 0`
   filter**, contradicting `recordWish` and the 0007 migration backfill.
   `src/db.ts`.
3. **`mergeClusters` dropped the merged cluster's client breakdown.** It
   deleted the from-cluster's rows and never added them to the target.
   `src/db.ts`.
4. **The `/ship` route accepted a session with no login.** The
   pending-claim cookie the server hands to every anonymous visitor who
   starts a claim is signed in the same format with the same secret and
   carries `login: ""`. Copying it into `tw_session` shipped a wish.
   `src/auth.ts` (readSession) and `src/index.ts` (handleShip).
5. **The admin panel could write an empty `claim_login`** — `String(x ??
   "unknown")` returns "" for an empty form field, because `??` only
   catches null and undefined. `src/admin.ts`.
6. **The grouped sample rows counted a sample window, not the cluster.**
   The count was taken in JavaScript over the twelve most recent wishes, so
   a cluster with sixteen wishes read "4 times" and the table never added
   up to the number in the heading above it. `src/board.ts`, `src/db.ts`.
7. **The nav links were 34px tall at 761px and above.** The 44px rule was
   inside the `max-width:760px` media query, so a tablet got a smaller
   target than a phone. `src/html.ts`.
8. **The sticky filter bar was cut off by the header.** It sat in a
   `.wrap` of its own, exactly as tall as the bar, so it had nowhere to
   travel and the top of it was hidden behind the header. Also, the
   `--topbar-h` token was a hand-measured number and was one pixel short
   at every width, because the header's 3px border sits outside its
   content box. `src/html.ts`, `src/board.ts`.

### What I got wrong

I put a backtick inside a CSS comment in a template literal. `tsc --noEmit`
passed, because the result was still valid TypeScript, and the Worker
crashed at runtime with `".wrap is not a function`. The check for it is
now in `tests/sticky.test.ts`: the stylesheet has to start with `:root{`
and end with `}` and have balanced braces. A template literal holding a
stylesheet needs its own check, because the compiler will not tell you.

### Lessons

- A sticky element cannot leave its containing block. If the containing
  block is exactly as tall as the sticky element, it does not stick.
- A hand-measured pixel value in a stylesheet is wrong the moment
  anything about the bar changes. Measure it at runtime.
- `String(value ?? "fallback")` does not fall back for an empty string.
- `ON CONFLICT DO NOTHING` is not always "keep the first row". When the
  conflict target has a flag that one side is authoritative about, the
  insert has to say which side wins.
- A sticky element taller than the space it has gets pushed up under the
  header. On a phone the filter bar is 242px of an 800px screen, so it
  cannot be sticky there at all. It scrolls below 560px and sticks above.
- Measuring the bar and writing the measurement back into a token the bar
  also depends on is circular. It settles on whatever the layout was at
  the moment it ran: 63px on a 66px bar. Take the bar's height from its
  contents, and measure that.

### Two things that bit me twice

The CSS lives in a template literal. A backtick inside a CSS comment ends
it. `tsc --noEmit` passes because the result is still valid TypeScript,
and the Worker crashes at runtime with `".wrap is not a function"`. It
happened twice on the same day, both times in a comment explaining the
first one. The stylesheet now has its own check.

### Three defects

1. **Unhandled rejection from the parallel reads.** The perf change
   started `getStats` alongside `listClusters`. If `listClusters`
   throws, the function unwinds and never awaits `statsPromise`, so its
   rejection is unhandled — a second error on the same request. Same
   shape in `renderCluster` (breakdown + grouped rows) and
   `renderWeekly`. Fixed by attaching the handler where the promise is
   made. `tests/parallel-reads.test.ts`.

2. **The entry page's client table was silently truncated.** The perf
   change windowed `getClientBreakdown` to 6 pairs per cluster for the
   board card, which shows four and says "+N more". The entry page has
   a table headed "Which agents filed these", and it showed six of ten
   and said nothing about the four it dropped. The window is now a
   parameter; the table asks for all of it.
   `tests/client-breakdown.test.ts`.

3. **`describeClients` dropped the rest silently.** The MCP card showed
   four clients of six with no indication. It now says "+N more".

### The `week_count` drift is live

`week_count` was a running counter that was never reset at the week
boundary and was not moved by a merge. The published entry read "27 this
week" against 25 wishes in total.

The fix is in the working tree (another agent's) and is correct — the
wish row is inserted first and the count is read from the wishes table
— but it is **not committed and not deployed**. The committed code at
`953f1df` still has `week_count = week_count + ?`. Migration
`0008_week_count.sql` is untracked and unapplied on production; the
applied migrations stop at `0007_votes_seeded.sql`.

I filed a wish and watched it: `count` 24 → 25, `week_count` 26 → 27.
Still drifting.

`tests/week-count.test.ts` fails 2 of 5 against the committed code.

### The auth bypass really is fixed

server hands every anonymous visitor, decoded it (`{"login":"",...}`),
replayed it under `tw_session` at `/ship`: **HTTP 401**, wish not
shipped. Replayed at `/claim`: 302 to `/auth/github`, no claim
written.

### The escaping is still sound
