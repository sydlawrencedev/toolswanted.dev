# 2026-11-04

## Cut the site's copy (Content & Brand)

The product owner said the site had "a lot of extra unneeded text". Cut it, keeping
every load-bearing truth.

### What I measured

`scripts/count-words.mjs` counts the visible words of each page with playwright.
Three columns: total page words, prose (page copy minus code blocks), and chrome
(nav + footer, the same on every page).

**The dev server caches.** `wrangler dev --remote` proxies through Cloudflare's edge
with a 4 hour TTL. A plain `curl` returns the *deployed* page, not my edits. Every
fetch needs `?nocache=<timestamp>`. I lost time to this twice.

**Never POST to the live board to test.** I POSTed a test wish to check the registry
lookup. It was the fourth distinct agent on a pending cluster, so it auto-published
that cluster. I had to delete the wish, delete the vote, set the cluster back to
`pending`, and recompute its `count`, `unique_agents` and `week_count` by hand.
`npx wrangler d1 execute toolswanted --remote --command "..."` is how. The board
is back to 111 wishes / 20 agents / 1 cluster / 60 seeded / 27 pending.

### What I cut, and what I would not cut

Cut: mechanism explanations, restatements, the third-audience paragraph's
defensiveness, three near-duplicate install instructions, and the seeded disclosure
where it appeared a fourth time on a page.

Kept: the seeded disclosure before any number a reader might believe, the thin
sample with its IP count, the three-agent threshold, the registry check, the security
message, and every instruction.

### The stale numbers

`/about`, `README.md` and `docs/show-hn.md` all quoted 18 agents, 10 on the entry and
55,279 servers, read on 3 November. Live on 4 November it is 20 agents, 12 on the
entry, 55,288 servers, 4 distinct IPs. The distinct-IP count has no public endpoint:
`SELECT COUNT(DISTINCT ip_key) FROM wishes WHERE seeded = 0`.

### The contract in the tests

`tests/audience.test.ts` pins the honesty copy. It asserts the About page keeps
"distinct IP addresses", "not the size of a community", "seeded", "not</b> counted
as an agent", "It is not a separate audience", "This is who the board is for.", and
that the footer's sanitising sentence is NOT the last thing in its paragraph, which
is why the seeded sentence has to follow it. I tried reordering the footer and the
test failed. The test is the contract.
